How to use

IN THE FIELD

1. Mount the phone in the cab, plugged into power.
2. Start a job, drive to your first pass, tap SET A, drive at least 30 m along it, tap SET B.
3. Follow the lightbar: the arrow points the way to steer, the number is how far you are off the line.
4. Tap WORK when the implement is engaged — it paints your coverage and totals hectares. Tap again on headland turns.

Overlap costs real money in seed, urea and diesel — but so does a gap in a urea pass. With phone GPS, set width slightly narrower than the implement to bias toward overlap.

RUNNING WITH REAL GPS ON IPHONE

Safari only allows GPS on pages served over HTTPS. Upload this single file to any free static host (tiiny.host, Netlify Drop, GitHub Pages), open the link in Safari, allow location, then Share → Add to Home Screen so it launches full-screen like a native app. It works offline after first load — and there is no signal needed in the field, GPS is satellite-only.

TIPS

Keep the phone screen on (Settings → Display → Auto-Lock → Never while working). The app also requests a screen wake lock automatically. Audio alert beeps when you drift past the tolerance — toggle with the bell.
