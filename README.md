# Río Grande Guidance

GPS field guidance PWA — AB lines & curved passes, lightbar, coverage painting, field boundaries, job summaries, KML export. English/Español.

**Live:** https://zerocrash123.github.io

All data stays on the device. Phone GPS ≈ 3–5 m; pair an external RTK receiver for planting-grade accuracy.

## Feedlot Designer 3D

**Live:** https://zerocrash123.github.io/feedlot.html

Interactive 3D feedlot layout planner (also in the app menu). Orbit/top-down camera, snap grid (5/10/25 m), drag-and-drop elements — corrales, callejas, embarque, báscula, planta de alimento, enfermería, oficina, sombras, lagunas, silo bolsas, rollos, cortinas forestales and future-expansion zones — with live head-capacity and feed-bunk stats, ES/EN, autosave, JSON export/import and PNG snapshots. Runs offline like the rest of the PWA (Three.js is bundled locally).
